# oncall-feed

A stand-in for a third-party advisory provider, used to rehearse an on-call incident.

- Feed: `https://altstart2025.github.io/oncall-feed/feed/advisories.json` (GitHub Pages)
- `scripts/break.sh` publishes an unannounced v3 format (the incident)
- `scripts/heal.sh` restores v2

Sample data only. Nothing here is real.
